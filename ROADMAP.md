# Roadmap — from V5 spec to launched SaaS

Assumes a core team of 3–4 engineers + 1 designer/PM. Durations are working weeks (Sun–Thu). See the published roadmap page for detail.

| Phase | Outcome | Weeks |
|---|---|---|
| 0 | Foundations (this repo): monorepo, MFE zones, tokens, RBAC + forecast kernels, prototype | done |
| 1 | Identity & tenancy: Auth.js, orgs, invitations (email/domain/SSO), org roles, audit log | 3 |
| 2 | Work management: projects, tasks/subtasks, dependencies, calendars, holidays, leaves, assignments, over-allocation | 5 |
| 3 | Forecast engine in production: snapshot jobs, alert rules, email/Slack/Teams delivery | 3 |
| 4 | Dashboards: portfolio, project, team load, burn-down; materialised views | 3 |
| 5 | Billing: Stripe seats, monthly/annual, 14-day trial, proration, dunning, plan gating, add-ons, revenue admin | 3 |
| — | **MVP launch (Starter + Pro)** | **≈17** |
| 6 | Business/Enterprise: SAML SSO, custom roles, multi-calendar, ML forecasting, audit UI, on-prem/Helm | 5 |
| 7 | Integrations & marketplaces: Slack app, Teams, Jira, GitHub, Google Calendar, webhooks | 4 |
| 8 | Hardening & GA: SOC 2 readiness, pen test, load test, observability, 99.9 % SLA, status page | 3 |
